# 🎲 Number Guessing Game

A simple and fun game where you guess a random number between 0 and 99.

## ✨ Features
- Random number generated by the program
- "Higher" or "Lower" hints after each guess
- Maximum 10 attempts per round
- Shows number of attempts when you win
- Reveals the correct number if you lose
- Play again option without restarting the program

## 🚀 How to Run
```bash
python guess_number.py
```

# 🎲 بازی حدس عدد

یک بازی ساده و جذاب برای حدس زدن عدد تصادفی بین ۰ تا ۹۹.

## ✨ قابلیت‌ها
- انتخاب تصادفی عدد توسط برنامه
- راهنمایی «بزرگتر است» یا «کوچکتر است»
- محدودیت ۱۰ بار تلاش
- نمایش تعداد دفعات حدس بعد از برد
- نمایش عدد صحیح بعد از باخت
- امکان بازی مجدد بدون بستن برنامه

## 🚀 نحوه اجرا
```bash

```
