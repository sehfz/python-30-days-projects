# 🎯 Word Guessing Game

A simple hangman-style word guessing game.

## ✨ Features
- Random word selection from a list
- Display word with underscores for unguessed letters
- Track guessed letters
- Maximum 6 wrong attempts
- Win/Lose conditions

## 🚀 How to Run
```bash
python word_guess.py
```

# 🎯 بازی حدس کلمه

یک بازی ساده برای حدس زدن کلمات.

## ✨ قابلیت‌ها
- انتخاب تصادفی کلمه از لیست
- نمایش کلمه با خط‌تیره برای حروف حدس‌زده نشده
- نمایش حروف حدس‌زده شده
- حداکثر ۶ بار اشتباه
- شرایط برد و باخت

## 🚀 نحوه اجرا
```bash
python word_guess.py
```
