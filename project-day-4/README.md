# 🔒 Password Strength Checker

A tool that checks password strength and provides suggestions for improvement.

## ✨ Features
- Checks password length (minimum 8 characters)
- Checks for uppercase letters (A-Z)
- Checks for lowercase letters (a-z)
- Checks for numbers (0-9)
- Checks for symbols (!@#$%^&*())
- Scores passwords as Weak / Normal / Strong
- Provides specific improvement suggestions
- Check multiple passwords in one session

## 🚀 How to Run
```bash
python strength_checker.py
```

# 🔒 چک‌کننده قدرت رمز عبور

ابزاری برای بررسی قدرت رمز عبور و ارائه پیشنهادات برای بهبود آن.

## ✨ قابلیت‌ها
- بررسی طول رمز (حداقل ۸ کاراکتر)
- بررسی وجود حروف بزرگ (A-Z)
- بررسی وجود حروف کوچک (a-z)
- بررسی وجود اعداد (0-9)
- بررسی وجود نمادها (!@#$%^&*())
- امتیازدهی به رمز (ضعیف / نرمال / قوی)
- ارائه پیشنهادات خاص برای بهبود
- امکان بررسی چندین رمز در یک جلسه

## 🚀 نحوه اجرا
```bash
python strength_checker.py
```
