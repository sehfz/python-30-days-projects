# 🔬 Scientific Calculator

A command-line scientific calculator with advanced mathematical functions and support for operations on multiple numbers.

## ✨ Features
- Basic operations: Addition, Subtraction, Multiplication, Division (with support for multiple numbers)
- Power (x^y)
- Square Root (√x)
- Trigonometric functions: Sine, Cosine, Tangent (in degrees)
- Natural Logarithm (ln)
- Error handling for division by zero, negative square root, and invalid logarithm

## 🚀 How to Run
```bash
python scientific_calculator.py
```

# 🔬 ماشین حساب علمی

یک ماشین حساب خط فرمان با توابع پیشرفته ریاضی و پشتیبانی از عملیات روی چند عدد.

## ✨ قابلیت‌ها
- عملیات پایه: جمع، تفریق، ضرب، تقسیم (با پشتیبانی از چند عدد)
- توان (x^y)
- ریشه دوم (√x)
- توابع مثلثاتی: سینوس، کسینوس، تانژانت (بر حسب درجه)
- لگاریتم طبیعی (ln)
- مدیریت خطاهای تقسیم بر صفر، ریشه عدد منفی، و لگاریتم نامعتبر

## 🚀 نحوه اجرا
