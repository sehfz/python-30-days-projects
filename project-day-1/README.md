# 🧮 Calculator

A simple command-line calculator with four basic operations.

## ✨ Features
- Addition, Subtraction, Multiplication, Division
- Handles division by zero
- Option to calculate multiple times

## 🚀 How to Run
```bash
python calculator.py
```
