# 🌤️ Weather App

A simple command-line weather app that fetches real-time weather data from wttr.in API.

## ✨ Features
- Get current weather for any city
- Shows: Condition, Temperature, Wind, Humidity
- Simple and clean output
- Error handling for invalid city names and connection issues

## 🚀 How to Run
```bash
python weather_app.py
```

## 📦 Requirements
```bash
pip install requests
```
