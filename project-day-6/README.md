# 📒 Contact Manager

A command-line contact manager that stores contacts in a JSON file.

## ✨ Features
- Add new contacts (name, phone, email)
- View all contacts with numbers
- Search contacts by name or phone
- Edit existing contacts
- Delete contacts
- Auto-save to JSON file

## 🚀 How to Run
```bash
python contact_manager.py
```

# 📒 مدیریت مخاطبین

برنامه‌ای خط فرمان برای مدیریت مخاطبین با ذخیره‌سازی در فایل JSON.

## ✨ قابلیت‌ها
- اضافه کردن مخاطب جدید (اسم، شماره، ایمیل)
- نمایش همه مخاطبین با شماره
- جستجوی مخاطب با اسم یا شماره
- ویرایش مخاطب
- حذف مخاطب
- ذخیره خودکار در فایل JSON

## 🚀 نحوه اجرا
```bash
python contact_manager.py
```
