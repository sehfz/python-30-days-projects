# ✅ To-Do List Manager

A command-line task manager that saves your tasks to a file.

## ✨ Features
- Add new tasks
- View all tasks with numbers
- Delete tasks by number
- Auto-save to file (tasks.txt)
- Load tasks automatically when program starts

## 🚀 How to Run
```bash
python todo_list.py
```

# ✅ مدیریت کارها

برنامه‌ای خط فرمان برای مدیریت کارهای روزانه با ذخیره‌سازی در فایل.

## ✨ قابلیت‌ها
- اضافه کردن کار جدید
- نمایش همه کارها به همراه شماره
- حذف کار با انتخاب شماره
- ذخیره خودکار در فایل (tasks.txt)
- بارگذاری خودکار هنگام اجرای برنامه

## 🚀 نحوه اجرا
```bash
python todo_list.py
```
